How to read this graph

Each color names an exact combination of proofs. Our route is the two-piece implementation variant. A zero count means that exact combination has no nodes; pairwise sharing may still occur in the purple all-three group.

Leiden community detection groups densely connected declarations. The clustering ignores colors, names of modules and previous coordinates. Names and edges are sorted and the algorithm uses a fixed seed. Communities are packed using their connections; each cluster has a fresh internal dependency layout. Cluster labels summarize module families after grouping. Neither screen distance nor a community boundary establishes mathematical equivalence.

References can occur in theorem statements, proof or definition bodies, and constructor or recursor structure. Shared reachability can represent common machinery as well as shared mathematical arguments.
