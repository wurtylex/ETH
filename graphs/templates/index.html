How to read these graphs

Clusters follow dependency connections using Leiden community detection. The layout uses a fixed seed and saved coordinates. Screen distance is a presentation choice, not mathematical distance or a count of dependency steps. Node size compresses the number of direct connections.

The full view uses seven membership colors; purple means shared by all three routes. The reduced view removes only OpenAI-only nodes and reclusters the induced graph. Its purple group combines all 5,358 declarations shared by Anthropic and our route, including 2,433 also used by OpenAI.

The default overview draws a fixed 10% sample of connections at 3.5% opacity. The graph JSON retains every displayed direct reference. Select a node to see all its connections within the active filters. Use Show cluster names to hide or show labels; Save view exports your chosen setting.

The three Lean-checked ETH endpoints use OpenAI, Anthropic, and an elementary two-piece core with reused recursion. The third route is an implementation variant: verification of the exact manuscript algorithm is separate. These are declaration-dependency graphs, not a proof that visually close declarations are mathematically equivalent.

Foundation modules are filtered after computing full compiled reachability. Membership colors retain that reachability; displayed edges are exact direct references without shortcut edges. Graph size and layout alone do not measure conceptual simplicity.
